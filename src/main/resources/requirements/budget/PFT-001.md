### 1. Create a Budget
* A user can create a budget for a given month and year
* The budget contains:
    - year (e.g. 2025)
    - month (1–12)
    - limit 

### 2. Update the Budget Limit
* User can update the budget’s limit
  - the limit must be greater or equal 0
* Only allowed if the budget is not locked

### 3. Track Spending
* System stores the total amount spent during that month.
* Spending is not yet entered manually — simulate it or leave space for it.
* The budget tracks: 
  - limit
  - spent
  - remaining (derived)

### 4. Lock Budget
* User can "lock" a budget once finalized
  - if the user tries to update the budget after locking, an error is returned "Trying to lock a budget that is already locked"
* When locked:
  - Limit can no longer be changed, if the user tries to update the limit, an error is returned "Trying to update a locked budget"
  - Spending can still be tracked

* Get the current month’s budget
